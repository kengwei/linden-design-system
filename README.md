# Linden Design System

A small, contract-first React design-system pilot. TypeScript contracts are the semantic source; deterministic generators produce tokens, icons, fonts, and Button artifacts.

## Public Boundary

This repository is a sanitized public snapshot of the design-system core. Private Figma operations, signed evidence, Linear workflow metadata, personal identity metadata, and portfolio materials are intentionally excluded.

## Development

```sh
pnpm install --frozen-lockfile
pnpm run validate
```
